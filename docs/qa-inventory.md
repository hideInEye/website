## 适配、可访问性与探索

- 所有检查视口必须满足 `scrollWidth <= clientWidth`，首屏必要区域不能被固定层遮挡。
- 键盘 Tab 能到达导航、CTA、主题切换、表单和后台主要动作，焦点环可见。
- `prefers-reduced-motion: reduce` 下页面可用，轨迹不会依赖动画传递信息。
- 探索场景 1：超长搜索词和零结果不会破坏布局。
- 探索场景 2：移动菜单打开后切换主题，再关闭菜单，页面不锁死滚动。
- axe 组件测试和 Playwright E2E 是自动证据；视觉截图是独立证据，不能互相替代。
