## 阶段 2：真实邮箱注册（已延期）

在服务器部署环境文件中使用真实值配置：

```dotenv
SITE_URL=http://admin.zylife.top
COOKIE_SECURE=false
ALLOW_INSECURE_HTTP=true

MAIL_MODE=smtp
SMTP_HOST=你的SMTP服务器
SMTP_PORT=465或587
SMTP_USER=你的SMTP账号
SMTP_PASSWORD=你的SMTP授权码或密码
MAIL_FROM=日落的足迹 <与SMTP服务匹配的发件地址>
```

说明：Compose 会把 `SITE_URL` 传给 API 作为 `APP_ORIGIN`。后端在端口为 `465` 时使用隐式 TLS；其他端口由 Nodemailer 按 SMTP 服务端协商。具体主机、端口、账号、授权码和发件地址必须以实际邮件服务商提供的信息为准。

以下执行项保留到用户重新启用邮箱注册时：

- [ ] 将 `.env` 权限设置为 `600`。
- [ ] 配置真实 SMTP 后重启 API。
- [ ] 使用一个未注册邮箱发起注册。
- [ ] 确认收到验证邮件，链接域名为 `http://admin.zylife.top`。
- [ ] 打开验证链接并确认账号状态变为 `ACTIVE`。
- [ ] 使用该账号登录。
- [ ] 临时提供错误 SMTP 配置做一次失败路径验收后恢复正确配置；确认失败邮箱可以再次注册。

验收标准：成功路径完成“注册 → 收信 → 验证 → 登录”；失败路径不残留阻止重试的用户记录。

## 阶段 3：管理员账号与文章发布

管理员不是默认账号，也不通过公开接口自助创建。用户已经在数据库中完成账号创建和角色设置；以下 SQL 仅保留为该操作的记录方式：

```sql
USE sunset_blog;

UPDATE users
SET role = 'ADMIN'
WHERE email = '替换为你的已验证邮箱'
  AND status = 'ACTIVE';

SELECT id, email, username, role, status, emailVerifiedAt
FROM users
WHERE email = '替换为你的已验证邮箱';
```

执行项：

- [x] 用户已确认数据库中已创建账号并设置为 `ADMIN`。
- [x] 用户已进入文章发布界面。
- [ ] 新建一篇草稿，保存并预览。
- [ ] 封面上传修复部署后发布文章，并从公开页面打开该文章。

验收标准：指定账号能够进入管理后台并完成一篇文章的创建、预览、发布和公开读取。
